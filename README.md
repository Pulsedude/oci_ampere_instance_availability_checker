# OCI Ampere instance availablity monitor

This script will check the availablity of OCI Ampere instance in your specific region. It will make a request to OCI API through python script then check the availablity status and print the result in the console.

# Usage
1. clone repo
2. rename `example.config` to `config`
3. then enter your OCI credentials in `config`
4. run `python start.py`

**That's it!**

Simple & very basic script :>
